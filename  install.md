# Guide d'installation de Phœnix-display

## Prérequis

- **Système** : Debian 13 (ou toute distribution récente avec support de X11/Wayland)
- **Matériel** : Processeur x86_64, GPU avec support OpenGL 3.3+, 32 Go RAM recommandé
- **Dépendances** : Les paquets listés ci-dessous seront installés automatiquement par le script.
